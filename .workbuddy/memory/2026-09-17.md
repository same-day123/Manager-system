## 第十七轮（产品经理）：首次 `push` 到 GitHub 成功 —— 顺带踩平「嵌套仓库 gitlink」大坑

阿辉给了 GitHub 用户名 `same-day123` + 一个 PAT，要求「先尝试有没有问题」（Q-04 / D-09 收口）。
**这一轮实际做成了，也爆出了一个会让"源码一行都进不去"的隐蔽坑。**

### 坑：嵌套仓库 → git 把两个源码目录整体当 gitlink（mode 160000）跳过
`RuoYi-Vue-fast/`、`RuoYi-Vue3/` 是**从上游 clone 来的**，各自目录里带着**自己的 `.git`**。
在外层仓库 `git add -A` 时，git 不会把里面的文件当普通文件，而是把整个子目录记成一条
**gitlink（mode 160000）**——即"这是个子模块的指针"。
**后果：首次提交只进了 38 个文件（docs/memory/脚本），两个源码目录下 279+18 个文件全部被静默跳过。**
`git status` 看着是"干净"的，所以第一眼完全看不出来 —— 这正是它危险的地方。

**排查路径**（可复用）：
- `git ls-files -s | grep 160000` → 看到两条 `160000` 记录，坐实 gitlink
- `git ls-tree HEAD` 里对应目录只显示一个 commit 哈希、**没有 blobs** → 源码确实没进去
- 反查 `RuoYi-Vue-fast/.git`、`RuoYi-Vue3/.git` 均存在 → 确认是嵌套仓库

### 修复：把内层 `.git` **移出**（不是删）
移到 `D:\code\_Manager_system_git_backup\RuoYi-Vue-fast.git` 与 `...\RuoYi-Vue3.git`。
**为什么移动而不是删除**：这是**可逆**的——万一以后要单独 pull 上游，把它移回原位即可；
删掉就没了。`git rm -r --cached` 掉两条 gitlink → 重新 `git add -A`。

### 结果
- 重新暂存：**665 条**，`gitlink = 0`、`node_modules = 0`
- `git commit --amend --no-edit` → **`57c81b9`，699 files changed, 82212 insertions(+)**
- 抽查确认含 `RuoYi-Vue-fast/src/main/java/com/ruoyi/project/laboratory/...` 等真实源码
- `git push origin main` → **成功**；`git ls-remote --heads` 核验：
  远端 `refs/heads/main = 57c81b9789876757c3ab8719a48573c62bf31d77` = 本地 `HEAD`，**一致**

### 推送过程中的第二个坑：PowerShell 抓不到 `git push` 输出
`git push` 失败时退出 128 但**日志文件是空的**。原因：PowerShell 5.1 下 `2>&1 | Out-File`
遇到原生命令写 stderr 会抛 `RemoteException` 中断管道，结果什么都没落盘。
**可行写法**（本机已验证）：
```powershell
$ErrorActionPreference='SilentlyContinue'
$env:GIT_TERMINAL_PROMPT='0'; $env:GCM_INTERACTIVE='never'
$out = & git -c credential.helper= push --progress $url main:main 2>&1
Set-Content -Encoding utf8 $log -Value ("EXIT=$LASTEXITCODE`n----`n$(($out|Out-String))")
```
三个要点：**① 变量接收再写盘**（不要 `| Out-File`）**② `-c credential.helper=` 禁用凭据助手**（否则卡在弹窗/静默失败）**③ `GIT_TERMINAL_PROMPT=0` 防交互挂起**。
> `cmd /c "git push ..."` 这条路**走不通**——PowerShell 工具直接以安全策略拦截 `cmd.exe`。

## 三条值得记的工程结论（下轮直接用）
1. ⭐ **H2 1.4.199 可用 `create alias <名> for "类.方法"` 补 MySQL 专有函数**，让生产 SQL 原样跑。三个实测细节：
