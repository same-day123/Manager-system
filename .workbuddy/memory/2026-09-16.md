### 为写提示词而做的代码勘察（结论已进任务卡，避免下次重查）
- `SecurityUtils.getLoginUser()` 在 SecurityContext 为空时**抛 ServiceException**，所以
  测试必须先装上下文；`SecurityUtils.getUserId()` 取的是 `LoginUser.userId` 字段，
  而 `new LoginUser(SysUser, Set)` 这个 2 参数构造**不设置 userId**，必须用 4 参数版。
- `SysUser.isAdmin()` = `userId == 1L`。**测试里普通用户绝不能用 userId=1**，否则权限测试全绿地失真。
- Mockito 版本是 Spring Boot 2.5.15 管理的 **3.9.0，不支持 mockStatic**；本机 `.m2` 里另有 5.11.0 但
  不建议升（会把 Mockito 拉到需要 JDK 11+）。测试统一用 `SecurityContextHolder` 方案。
- 前端仓库**只有 `yarn.lock`，没有 `package-lock.json`** → CI 里不能写 `npm ci`。
- `RuoYi-Vue3/.env.production` 的 `VITE_APP_BASE_API = '/prod-api'` →
  nginx 的 `proxy_pass http://lab-backend:8080/` **末尾斜杠不能漏**，否则前端全接口 404。
- `application.yml` 里 `ruoyi.profile` 写死成 Windows 路径 `D:/ruoyi/uploadPath`，
  容器里要靠环境变量 `RUOYI_PROFILE` 覆盖（Spring Boot relaxed binding 生效，不用改配置文件）。
- MySQL 官方镜像按**文件名字母序**执行 `/docker-entrypoint-initdb.d` → 7 个 SQL 直接挂进去顺序全反，
