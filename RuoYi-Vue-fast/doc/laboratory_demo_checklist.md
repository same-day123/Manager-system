# 实验室资产与报修管理系统演示验收清单

## 准备数据
- 准备 3 个实验室：计算机实验室、电子实验室、综合实训室。
- 准备 3 类资产：仪器设备、计算机设备、办公设备。
- 准备 5 条报修单：待审核、待维修、维修中、已完成、已拒绝各至少一条。

## 演示流程
- 管理员登录，维护实验室房间并新增资产。
- 管理员批量导入资产 Excel，确认资产编号唯一校验生效。
- 普通用户登录，提交报修并上传故障图片。
- 教师登录，审核报修并依次流转到待维修、维修中、已完成。
- 普通用户查看报修详情时间线，并对已完成报修进行评分评价。
- 管理员查看首页统计看板、报修趋势、故障等级分布、实验室维修次数和维修费用。
- 管理员打开资产履历，确认入库、调拨、状态变更记录可追踪。
- 管理员打开资产二维码标签，确认扫码入口内容绑定资产 ID。

## 异常场景
- 重复资产编号导入应失败并提示。
- 维修中的资产不能删除。
- 存在资产的实验室不能删除。
- 普通用户不能查看或处理他人报修单。
- 报修状态不能从待审核直接跳到已完成。
