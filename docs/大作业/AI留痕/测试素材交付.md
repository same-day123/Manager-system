### 4.3 ⚠️ 一个已知且无害的构建噪声（**必须如实说明**）

构建日志里会出现这样一段：

```
System.exit() or native command error interrupted process checker.
java.lang.IllegalStateException: Cannot use PPID 4052 process information. Going to use NOOP events.
    at org.apache.maven.surefire.booter.PpidChecker.checkProcessInfo(PpidChecker.java:155)
```

| 项 | 说明 |
| --- | --- |
| **根因（本轮实测定位）** | Surefire 2.22.2 的 `PpidChecker` 会调 **Windows 的 WMIC** 查询父进程是否存活；本机安全策略拦截了 WMIC → 该次探测失败 → Surefire **自行降级为 NOOP events** 并留下一个 `jvmRun1.dump` 文件 |
| **影响** | **无**。测试照常全部执行：本轮 **49/49 通过、BUILD SUCCESS**。dump 文件与测试结果无关 |
| **为什么写进文档** | 不写的话，助教/老师看到 `IllegalStateException` 会**误读成"构建出问题了"**。写清楚反而是工程透明度 |
