# AI 留痕

> **为什么要有这个目录**
> 任务书对《AI 辅助开发实践报告》有两条硬指标：
> - 展示**至少 3 处**完整提示词（Prompt）及生成结果
> - 对 AI 生成代码进行人工审查，指出**至少 1 处**需要修改的地方及原因
> 另外还有一条红线：**文档查重率 >30%（含代码注释）该项得 0 分**。
>
> 所以：**每完成一张任务卡，就在这里留一份记录。** 不要等写报告的时候再回忆——那时候细节全丢了。
> 这份记录同时也是答辩 PPT「AI 工具实际使用截图」的素材来源。

---

## 使用方式

1. 复制下面的模板，新建文件 `T?-YYYY-MM-DD.md`（例如 `T1-2026-09-18.md`）
2. 截图统一放 `截图/` 子目录，文件名带编号（`T1-01-提示词.png`、`T1-02-测试通过.png`）
3. **「人工修改点」是最值钱的一栏**，宁可多写几条

## 给文档组的提醒

**这个目录下的内容不能直接粘进 PDF。** 查重率 >30% 的时候文档项直接 0 分，而且任务卡的提示词本身也是 AI 生成的文本，粘进去风险更高。

正确用法是：**把这里当"事实来源"，换个说法、换个结构重新组织进文档。**
