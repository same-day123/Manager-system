【补充：一次已知且无害的环境噪声 —— 必须如实说明，不能当成"全绿无杂音"】
日志里会出现 surefire 的 `PpidChecker` 报错与 target/surefire-reports 下的
`*-jvmRun1.dump` 文件，内容为：

  System.exit() or native command error interrupted process checker.
  java.lang.IllegalStateException: Cannot use PPID 4052 process information. Going to use NOOP events.
      at org.apache.maven.surefire.booter.PpidChecker.checkProcessInfo(PpidChecker.java:155)
      at org.apache.maven.surefire.booter.PpidChecker.isProcessAlive(PpidChecker.java:116)
      at org.apache.maven.surefire.booter.ForkedBooter$2.run(ForkedBooter.java:214)

根因（本轮实测定位）：Surefire 2.22.2 的 PpidChecker 会调 Windows 的 WMIC 去查父进程是否还活着；
本机安全策略拦截 WMIC → 该次探测失败 → 它**自行降级为 NOOP events** 并写一个 dump 文件。
**测试照常全部执行**：本次 49/49 通过、BUILD SUCCESS，dump 与测试结果无关。
（历史记录里把它记作「WMIC 告警·干扰项」，本轮把根因钉到了具体类与行号。）
