System.exit() or native command error interrupted process checker.

    at org.apache.maven.surefire.booter.PpidChecker.checkProcessInfo(PpidChecker.java:155)

根因（本轮实测定位）：Surefire 2.22.2 的 PpidChecker 会调 Windows 的 WMIC 查父进程是否存活；
本机安全策略拦截 WMIC → 该次探测失败 → 它自行降级为 NOOP events 并留下一个 dump 文件。
测试照常全部执行：本次 49/49 通过、BUILD SUCCESS。这个 dump 与测试结果无关，
列在这里是为了不让它被误读成"构建出问题了"。
