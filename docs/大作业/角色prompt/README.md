| 文件 | 用在哪 | 动作 |

| `文档负责-创建提示词.md` | **新建**一个会话（工作目录 `D:\code\Manager_system`） | 整段粘贴 → 先读 AGENTS.md 与 D1 卡，**报素材缺口**再动手 |

## 待阿辉确认（统一收件箱）

各角色遇到**需要阿辉拍板、但不卡住当前这一步**的事 → **追加一行**到 `docs/大作业/待阿辉确认.md`
（事项 / 选项 / **你的建议** / 卡住了谁），阿辉一次看完、一次回复；
**当场卡住的**（不答就没法继续）→ **就在会话里直接问**，不进收件箱。
**五份提示词里都已写明这条协议**，登记时**必须带建议**。
