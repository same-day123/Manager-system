2 测试策略与测试金字塔

2.1 比例与理由

层用例数占比为什么这么分
单元测试3367%报修状态机、权限判定、字段校验三块规则密集、分支多，需要毫秒级快速反馈；用 Mockito 隔离依赖，专攻「调用契约」

关于端到端占比低：本项目没有引入 Selenium / Playwright，原因有二：一是离线开发环境无法安装浏览器驱动，二是系统体量（4 个业务模块）不足以摊薄 E2E 框架的维护成本。端到端场景由人工按演示路径实测替代（登录、看板、台账、报修闭环四条路径共 73 条接口请求，0 个 4xx/5xx）。这是有意的设计取舍，不是遗漏。

3.3 两个踩坑记录

  • 验收一律用 clean test：不带 clean 时 target/test-classes 会残留上一次编译的类，导致 mvn test 与 clean test 结果不一致——项目在对照实验中因此失效过一轮。
  • 集成测试不加 @Transactional：测试类用 @BeforeEach 清表 + 铺基线数据，保证用例间互不污染，同时避免事务回滚掩盖「落库是否真实发生」这一被测对象本身。

4.2 状态机的两层覆盖

状态机是全系统风险最高的规则（写错会静默放行非法操作），因此覆盖分两层：

  • 契约层（保留的 5 个反射用例）：直接验证 4 条合法流转 + 16 组非法流转 + 幂等（同状态放行）矩阵。缺点是跨过了公开入口。
  • 入口层（新增 3 个用例）：经 updateLabRepair 公开入口触发，补上契约层测不到的三件事——合法流转时持久层真的收到正确参数、非法流转时整轮零写库（verify(..., never())）、状态不变时履历记的是「维修信息更新」而非状态流转。

两层并存是有意决策：契约层穷举矩阵、入口层验证编排，互不弱化。

5.2 看板方言垫片（不改生产代码补齐 H2 方言）

看板 SQL 使用 MySQL 专有的 date_format() / date_sub()，H2 不支持。本项目的解法：在测试侧用 H2 的 create alias ... for "类.静态方法" 注册两个同名等效函数，生产 mapper XML 一个字都没改就在 H2 上跑通了全部 8 条查询。垫片放在 src/test，不参与生产打包。

一个实现细节值得记录：date_sub 的第二个参数必须声明成 String——H2 会把 interval 6 day 变成 INTERVAL '6' DAY 传进来；声明成 int 报数据转换错误，声明成 Object 报十六进制解析错误。垫片自检用例（DB-01）验证的是函数真的算得出正确值，而不是只验证注册记录存在。

5.3 基础设施自检与数据铺底

每个集成测试类自带 @BeforeEach 基线（房间/资产/报修数据），不依赖执行顺序；DB-01 作为基础设施自检用例单独存在，方言垫片失效时第一个红的就是它，便于定位。

9 限制与如实说明

以下四条是本测试工作的已知边界，均照实说明、未作美化：

1. 行覆盖率 / 分支覆盖率百分比未能产出。 本项目全程离线构建，本地 Maven 仓库缺 jacoco-maven-plugin 与 org.jacoco.core，仅有运行时 agent jar，无法生成覆盖率报告；引入 JaCoCo 还需修改 pom.xml 构建段，超出测试工作的改动边界。因此本文以用例↔业务规则追溯矩阵（第 7 章）作为需求维度的覆盖证据，辅以断言数 177 与交互校验 27 两个可机械复核的统计量，不给出未经实测的覆盖率百分比。 2. 构建日志含一段无害噪声。 Surefire 2.22.2 的 PpidChecker 会调用 Windows WMIC 查询父进程存活状态，本机安全策略拦截了 WMIC，Surefire 随即自行降级为 NOOP events 并留下一段 IllegalStateException: Cannot use PPID ... 堆栈与一个 jvmRun1.dump 文件。该噪声不影响测试：本轮 49/49 通过、BUILD SUCCESS。在此说明是为了避免读者把这段堆栈误读为构建故障。 3. 事务回滚为间接覆盖。 「注入异常后断言双表回滚」的直接验证未做：本机离线仓库中 MyBatis Mapper 是 JDK 动态代理，@SpyBean 对其生效性存疑，硬造一个假回滚断言不如如实说明。事务完整性目前由 IT-03「非法流转后单据、履历、资产三处均不变」间接覆盖。 4. 测试聚焦 Service 与 Mapper 两层。 29 个生产类中被测试直接触达的核心类 11 个；Controller 层的权限注解通过真实环境端到端实测验证（四条演示路径 73 条接口 0 个 4xx/5xx），Entity 与纯常量/图形工具类不单独编写用例。
